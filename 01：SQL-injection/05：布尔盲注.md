# 布尔盲注

## 一、环境

- 靶场：自建本地 sqli-labs-master 靶场
- 工具：Burp Suite + HackBar
- 数据库：MySQL

## 二、什么是布尔盲注

当 SQL 注入点存在，但是页面**不会直接显示查询结果或报错信息**时，可以通过判断页面对 **True / False** 条件的不同响应来获取数据。

核心就是：

**让数据库回答“是”还是“否”,从而确定正确信息。**

## 三、基本思路

先判断注入点 → 构造一个正确条件和错误条件 → 观察页面响应是否不同 → 根据 True / False 推测数据库中的数据。

例如：

```sql
' and 1=1--+
```

条件成立。

```sql
' and 1=2--+
```

条件不成立。

如果两个请求返回的页面存在明显差异，就说明可能存在布尔盲注。

## 四、判断数据

例如想判断当前数据库名的第一个字符：

```sql
' and substring(database(),1,1)='a'--+
```

如果页面表现为 True，说明：

```text
数据库名第 1 个字符 = a
```

如果 False，则继续尝试其他字符。

也可以使用 ASCII：

```sql
' and ascii(substring(database(),1,1))=97--+
```

这里：

- `substring()`：截取字符串
- `ascii()`：把字符转换成 ASCII 数值

## 五、常用函数

### 1. database()

获取当前数据库名：

```sql
database()
```

### 2. substring()

截取字符串：

```sql
substring(database(),1,1)
```

表示从第 1 个字符开始，取 1 个字符。

例如：

```text
test
 ↓
t
```

### 3. length()

获取字符串长度：

```sql
length(database())
```

例如：

```text
test → 4
```

可以先判断数据库名有多少个字符，再逐个判断。

### 4. ascii()

获取字符对应的 ASCII：

```sql
ascii(substring(database(),1,1))
```

例如：

```text
t → 116
```

## 六、常见判断方式

### 字符判断

```sql
substring(database(),1,1)='t'
```

### ASCII 判断

```sql
ascii(substring(database(),1,1))=116
```

### 长度判断

```sql
length(database())=4
```

这些本质上都是：

```text
构造条件
   ↓
True / False
   ↓
观察页面变化
   ↓
逐步推测数据
```

## 七、和联合查询、报错注入的区别

### 联合查询

```text
数据库查询结果
      ↓
直接显示在页面
```

### 报错注入

```text
数据库报错
      ↓
数据进入错误信息
      ↓
页面显示错误信息
```

### 布尔盲注

```text
数据库不会直接告诉你数据
      ↓
只能构造 True / False
      ↓
通过页面响应差异判断
      ↓
逐字符获取数据
```

所以布尔盲注的特点就是：

**看不到数据本身，只能通过“条件是否成立”间接推测数据，因而成本较大。**

## 八、我的理解

我之前容易把盲注理解成“没有回显就没办法注入”。

实际上：

**没有直接回显 ≠ 没有 SQL 注入。**

只要可以通过页面响应判断：

```text
条件成立 → A
条件不成立 → B
```

就可以利用这种差异进行盲注。

布尔盲注本质上就是把：

> “数据库里的数据是什么？”

转换成很多个：

> “这个条件成立吗？”

然后通过不断判断，最终把数据一点一点推出来。

## 九、关键知识点

```text
布尔盲注
├── True / False 判断
├── database()
├── length()
├── substring()
├── ascii()
└── 逐字符推测数据
```

核心记忆：

**布尔盲注 = 没有直接数据回显，通过 True / False 的页面差异来推测数据。**
