# 堆叠查询

## 二、什么是堆叠查询

堆叠查询（Stacked Query）是指：

**在一次数据库请求中，通过分号 `;` 将多条 SQL 语句连接起来执行。**

例如：

```sql
SELECT * FROM users; SELECT database();
```

前一条 SQL 执行完成后，再执行后一条 SQL。

所以可以简单理解为：

```text
一条请求
   ↓
SQL 语句 1
   ↓
SQL 语句 2
   ↓
SQL 语句 3
```

## 三、基本判断

能堆叠查询的关键是测试 `;` 后面能不能继续执行新的 SQL。

例如：

```sql
' ; SELECT sleep(5)--+
```

如果响应出现明显延迟，说明后面的 SQL 语句可能被数据库执行。

实际是否支持堆叠查询，还取决于：

- 数据库类型
- PHP/数据库驱动
- 当前执行 SQL 的方式
- 程序是否允许一次执行多条语句

所以**发现 SQL 注入 ≠ 一定支持堆叠查询**。

## 四、核心符号

### `;`

分号用于结束一条 SQL 语句：

```sql
SELECT 1;
SELECT 2;
```

表示执行两条 SQL。

在堆叠查询中，`;` 是最重要的符号。

## 五、堆叠查询能做什么

因为可以执行第二条 SQL，所以理论上能够执行原本查询之外的操作。

例如：

```sql
SELECT database();
SELECT user();
```

也可以执行数据修改类语句，例如：

```sql
UPDATE users SET password='test' WHERE username='admin';
```

甚至可以执行创建、删除等 SQL 操作。

因此堆叠查询的影响通常比单纯的查询型注入更广。

## 六、和联合查询的区别

### 联合查询

使用：

```sql
UNION SELECT ...
```

本质上还是**把多个查询结果合并到一个结果集中**。

```text
原查询
  +
UNION 查询
  ↓
一个结果集
```

### 堆叠查询

使用：

```sql
;
```

让数据库继续执行**另一条独立 SQL**。

```text
SQL 1
  ↓
SQL 2
  ↓
SQL 3
```

所以：

**联合查询 = 合并查询结果**

**堆叠查询 = 连续执行多条 SQL**

## 七、注意事项

堆叠查询并不是所有环境都支持。

例如在 PHP + MySQL 环境中，具体能不能执行多条语句，还与使用的数据库 API 有关。

因此实际测试时不能看到 SQL 注入就直接认为：

```text
; SELECT ...
```

一定可以执行。

需要先验证当前环境是否支持。

## 八、我的理解

我之前容易把 SQL 注入理解成：

> “在原来的 SQL 后面加一点自己的条件。”

而堆叠查询更进一步：

> **不仅可以修改原来的 SQL，还可能让数据库继续执行一条新的 SQL。**

所以它的核心不是某个特殊函数，而是：

```text
结束当前 SQL
    ↓
;
    ↓
继续执行新的 SQL
```

## 九、关键知识点

```text
堆叠查询
├── 核心符号：;
├── 一次请求执行多条 SQL
├── 是否支持取决于数据库和驱动
├── 可以执行查询语句
└── 理论上也可以执行增删改等语句
```

核心记忆：

**堆叠查询 = 使用 `;` 结束当前 SQL，并继续执行后面的另一条 SQL。**
